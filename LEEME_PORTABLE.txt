NILO 05.7 - EDICION PORTABLE DE WINDOWS 64 BITS
================================================
No hace falta instalar Python ni tener permisos de administrador.
NO es un EXE autonomo precompilado ni incluye Python dentro del ZIP inicial:
la primera ejecucion descarga automaticamente Python embebible oficial (11 MB).
Una vez completada, podes copiar la carpeta entera a otra PC y ejecutarla
incluso sin internet para arrancar. Las consultas Gemini/Groq siguen requiriendo red.

COMO INICIAR
1. Descomprimi Nilo_05_7 en una carpeta con permisos de escritura.
2. Ejecuta INICIAR_NILO.bat. El primer inicio prepara su propio python\python.exe.
3. El asistente ofrece importar CONFIGURACION de la version anterior y,
   por separado, una COPIA de la partida. Nilo viejo no se modifica.
4. Cuando termines, para otra computadora lleva la carpeta completa, incluido
   python\, config.env y nilo_mundo.sqlite3 (si queres continuar el mundo).
   No ejecutes dos copias del mismo archivo SQLite en una carpeta compartida.

SI LA NOTEBOOK BLOQUEA DESCARGAS
- Descarga en otra PC, desde python.org, este ZIP oficial:
  https://www.python.org/ftp/python/3.12.10/python-3.12.10-embed-amd64.zip
- Copialo SIN descomprimir en la misma carpeta donde esta INICIAR_NILO.bat.
- Hace doble clic nuevamente en INICIAR_NILO.bat. Verifica el SHA256, descomprime
  el motor en python\ y configura rutas automaticamente.
- O prepara por primera vez el portable en tu PC personal y lleva la carpeta
  Nilo_05_7 COMPLETA a la notebook del trabajo.

SEGURIDAD E INTEGRIDAD
- SHA256 exigido al ZIP del interprete:
  4acbed6dd1c744b0376e3b1cf57ce906f9dc9e95e68824584c8099a63025a3c3
- Solo se extrae el ZIP si coincide. Nunca se usa un Python instalado en Windows.
- No cambia PATH, registro, archivos de sistema ni configuracion de seguridad.
- La notebook debe permitir ejecutar programas .exe locales y scripts BAT.
- En algunos equipos gestionados por una organizacion las politicas pueden
  impedir ejecutar software portable. Respeta las politicas de tu organizacion.

Respaldos e importacion usan el mismo Python portable.
Para borrar el programa, cerra Nilo y elimina su carpeta, preservando antes
los respaldos del mundo que quieras conservar.
