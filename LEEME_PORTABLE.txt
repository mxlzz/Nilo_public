NILO 0.7.0 — EDICIÓN PORTABLE DE WINDOWS 64 BITS
================================================

No necesita instalar Python en Windows ni permisos de administrador para
configurar el entorno local. El ZIP inicial NO contiene un EXE autónomo:
en el primer inicio descarga CPython 3.12.10 embebible oficial desde python.org,
verifica su SHA256 y lo guarda dentro de la carpeta de Nilo.
Los modelos Gemini y Groq requieren Internet y tus propias claves API.

INSTALACIÓN
1. Extraé Nilo-0.7.0.zip en una carpeta NUEVA con permisos de escritura.
2. Ejecutá INICIAR_NILO.bat; se prepara python\\python.exe en esa carpeta.
3. El asistente puede copiar CONFIGURACIÓN y, por separado, la PARTIDA anterior.
   La instalación original permanece sin modificaciones.
4. Si importás una partida, verificá su información antes de retirar la versión
   anterior. Usá RESPALDAR_PARTIDA.bat para crear copias recuperables.

SI NO SE PERMITE DESCARGAR PYTHON
Descargá en otra PC el archivo oficial:
https://www.python.org/ftp/python/3.12.10/python-3.12.10-embed-amd64.zip
Copialo sin descomprimir junto a INICIAR_NILO.bat y repetí el inicio.
SHA256 esperado:
4acbed6dd1c744b0376e3b1cf57ce906f9dc9e95e68824584c8099a63025a3c3

TRAZABILIDAD
BUILD_INFO.json guarda el commit de compilación cuando se conoce, y
MANIFIESTO_SHA256.json contiene los hashes de los archivos incluidos.
El historial de la partida registra versión, commit y manifiesto.
Las versiones anteriores pueden no disponer de estos datos.

RESPALDOS Y SEGURIDAD
- Nunca compartas config.env: contiene tus credenciales de proveedor.
- No compartas la SQLite si no querés divulgar los recuerdos de Nilo.
- No abras simultáneamente dos programas sobre la misma base SQLite.
- Los ejecutables y Python quedan dentro de la carpeta de Nilo;
  el instalador no cambia PATH, registro ni archivos de Windows.
- Para volver a una versión anterior, conservá la carpeta y partida previas.
- No reemplaces los archivos de una versión antigua por los de esta.
- No se incluye ningún mundo, clave API ni copia personal en el ZIP.

Nilo 0.7.0 es una refactorización arquitectónica. No elimina necesariamente
los bucles históricos de autonomía. Groq no se verificó con una corrida real
en la evaluación de esta etapa.

Más detalles: README.md y docs\\NOTAS_VERSION_070.md.
