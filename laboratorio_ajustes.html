Perfil de ajustes

Excluir información opcional del contexto LLM

Una casilla marcada excluye ese campo de la solicitud calculada; una casilla desmarcada lo incluye. La posición, las necesidades, los proyectos activos y la evidencia física no pueden ocultarse. Omitir información del mensaje no elimina registros de Nilo.

Las comparaciones usan el constructor real de solicitudes, sin red ni consumo de API. Un escenario ejecuta el motor físico real dos veces con la misma semilla; la variante actual no modifica leyes físicas.

Variantes y aplicación

Aplicar guarda automáticamente el perfil anterior y registra una huella de integridad. No escribe archivos Python ni claves API. Reiniciá Nilo para garantizar la aplicación completa. Restaurar ajustes no cambia el día ni el mundo.

Backups de partidas (operación independiente)

Se usa el backup consistente de SQLite, incluyendo WAL. Nunca se sobrescribe la partida principal ni se vuelve automáticamente a un día anterior. Los backups se guardan en lab_profiles/world_backups; las copias restauradas, en lab_profiles/world_restores.
