# Principios y hoja de ruta de Nilo

1. **Motor → resultados, modelo → intenciones.** Una narración nunca modifica la física por sí misma.
2. **Experimentos reproducibles.** La ficha registra hipótesis, material, componentes, versión, método y resultado comprobado.
3. **Ampliación fundamentada.** El agente puede pedir nuevas capacidades generales; su autor revisa y decide. Aprobación no equivale a implementación: las reglas nuevas requieren código + prueba + versión Git.
4. **Necesidades que motivan, no misiones predeterminadas.** Autocuidado determinista y objetivos libremente elegidos. Evitar que las barras causen consumo continuo de llamadas LLM.
5. **Memoria acumulativa.** Preservar hechos, extraer resúmenes por etapas y preferencias adquiridas, mantener procedencia explícita.
6. **Nilo B futuro.** Base física compartida, perfiles de conocimiento separados, tiempo acelerado eficiente, generaciones y transferencia de cultura. No afirmar que un LLM está epistemológicamente vacío.

## Próximas ampliaciones físicas

- Geometrías de ensamblaje más ricas, materiales compuestos, estabilidad y desgaste.
- Energía térmica, transferencia de calor, combustión, transición agua-vapor y presión con límites materiales, cada una con pruebas deterministas.
- Construcciones de varias etapas, ensamblajes fijos, almacenamiento y logística.
- Fenómenos ecológicos y peligros causales concretos: clima, temperatura ambiental, calidad sanitaria de fuentes, lesiones recuperables. Sin inventar depredadores por narración.
- Expansión espacial del mundo y gestión de memoria de largo plazo (índices y resúmenes).

## Compatibilidad

Una partida migrada a 05 no necesariamente abre en 04: mantener la instalación anterior y su respaldo SQLite. El asistente de primer inicio **copia** configuración y partida; no las mueve.
