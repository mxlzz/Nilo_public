Punishment sí satisface criterio literal (slot elegible y cambio de STW), pero el análisis discriminante limita la interpretación: al aplicar la ecuación preexistente effect=(sus_actualizada*CHEM)>>8, ningún slot cumple effect>0 && effect>STW_pre-LTW_pre; además ticks478/479 no son múltiplos de tasas de ganancia/pérdida3/5 ni consolidación128. No interpretar coincidencia de todos los bytes como validación de ramas no ejercitadas. Las tres sesiones tienen estados iniciales diferentes, el sham carece de elegibilidad y no permite estimar efectos causales; CHEM relevante positivo no identifica por sí solo el origen exógeno/endógeno.

**Decisión:** cerrar esta serie como PASS de reproducción local limitada de transiciones observadas, exposición química y disponibilidad; no como validación de aprendizaje. Repetir el mismo protocolo con una dosis mayor sería una optimización no justificada. La próxima unidad debe preregistrar una condición **discriminante a partir del estado previo**, donde el modelo prediga diferencias de STW entre CHEM observado y contrafactual CHEM0, con fuente/owner/eligibilidad identificadas antes del cambio; si no hay oportunidades naturales, diseñar intervención sensorial documentada que las genere y un sham igualmente activo. Para consolidación LTW, capturar oportunidades de tick y diferencia STW-LTW no nula, no inferir estabilidad de los casos constantes. No reabrir N ni cambiar modelo sin evidencia útil. No se necesita ninguna nueva autorización/archivo del usuario. N STOP, G05/G09 y G-H6-CLOCK abiertas; main intacto.
